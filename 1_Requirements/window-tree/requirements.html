The program

WT-R1Plain C++17 and nothing else

  • C++17 and the standard library only, with no frameworks and nothing to install.
  • One class per file, so each node type and each walk can be read on its own.

WT-R2A form you can aim at

  • A settings window: a name box, Save, Close and Help, and an Advanced panel that starts disabled.
  • Everything draws on a 38x16 character canvas with coordinate rulers, so a click can be aimed by eye.
  • The screen redraws after every change.

The four walks

WT-R3Layout: measure up, arrange down

  • Measuring is postorder: a container cannot know its size until every child has reported.
  • Arranging is preorder: a child cannot know where it sits until its parent has fixed its origin.
  • The two logs must read as mirror images of each other.

Design WT-D1 WT-D7 Tests WT-T2

WT-R4Painting puts children on top

  • Painting is preorder for a visible reason: parents draw first, children draw over them, which is what puts widgets inside their window.
  • A hidden widget takes its whole subtree off the screen, and the window reshapes without it.
  • A disabled widget dims everything below it, drawn in parentheses.

WT-R5A click travels the DOM's route

  • A hit test descends to the deepest widget under the point.
  • Capture walks down from the root, and a disabled ancestor swallows the click before the target ever sees it.
  • The target raises an action that bubbles up until an ancestor knows what it means; unhandled, it falls off the top and is dropped, not crashed.

WT-R6Closing is a question

  • A postorder walk where every child answers before its parent decides.
  • One unsaved text box anywhere below keeps the window open.
  • Hidden widgets are asked too: invisible unsaved work is still unsaved work.

Ownership

WT-R7The tree is the ownership

  • Every widget owns its children through unique_ptr, so the tree's shape and the memory management are the same picture.
  • No other code frees a widget, and a reader can check it: the demo contains no new and no delete.
