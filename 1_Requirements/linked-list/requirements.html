The program

LL-R1Plain C and nothing else

  • C11 and the standard library only, with no C++ and no frameworks.
  • It builds from one command line with two source files, and with CMake for people who prefer that.

Design LL-D1 Tests LL-T7 LL-T9

LL-R2One menu item per operation

  • Eighteen operations in four groups: build, query, rearrange, and the circle.
  • Each item is answered by one small function, so a reader can read just the one they came for.

Design LL-D1 LL-D2 Tests LL-T1

LL-R3The list is always on screen

  • After every operation the list is drawn as boxes and arrows with a node count.
  • A circle ends with the way back to its head instead of NULL.

Design LL-D3 Tests LL-T2

The classics

LL-R4The classics, answered the classic way

  • Reverse, merge sort, the middle node, the nth node from the end, and a palindrome check.
  • Loop detection is the tortoise and the hare, run for real rather than read off a flag.
  • Merge sort is chosen on purpose: it is the list's own sort, with no jumping to an index.

Design LL-D5 LL-D6 Tests LL-T3 LL-T4

LL-R5A circle, and a game to justify it

  • The list can be bent into a circle, detected, broken, and rotated left by k.
  • The Josephus game counts every k-th person out of a fresh ring and prints the ring each round.
  • An oversized k must wrap rather than fail.

Design LL-D7 LL-D8 Tests LL-T5

LL-R6A question must not change the answer

  • The palindrome check reverses half the list to compare it, then puts it back exactly as it was.

Design LL-D6 Tests LL-T4

Safety

LL-R7A circle must never hang the program

  • Operations that walk toward NULL refuse to run while the list is a circle, and say why.
  • The drawing and the counting are safe on a circle, since both stop at the head.

Design LL-D3 LL-D4 Tests LL-T6

LL-R8Readable before clever

  • Every function that takes a node pointer lives in the list module.
  • The menu file keeps the typing, the guards and the program state, and nothing else.
  • Small functions, named constants, and comments that say why rather than what.

Design LL-D1 LL-D4 Tests LL-T7 LL-T8

LL-R9Menu numbers are append-only

  • A new item takes the next free number and is shown inside its group.
  • So a transcript written a year ago still describes the same session today.

Design LL-D9 Tests LL-T8

LL-R10Nothing is left behind

  • Clearing the list frees every node, and so does quitting, whether the list is straight or a circle.
  • A circle is straightened before it is freed, since it has no NULL for the freeing walk to stop at.
  • The game frees each person as they leave the ring.
