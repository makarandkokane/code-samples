The parts

LL-D1The header is the whole contract

  • One node struct and nineteen functions, grouped as building, questions, rearranging, the circle, showing, and the game.
  • Declarations only. Anything a caller does not need is static inside the module.

Requirements LL-R1 LL-R2 LL-R8 Tests LL-T1 LL-T7 Code LinkedList.h

LL-D2One function per operation

  • Every list operation on the menu maps to one list function, and the demo README carries that map.
  • The exceptions the README names are the sample list and clear, conveniences built from the others; the game likewise builds its ring before ListJosephus plays it.
  • The menu file holds one small handler per item: read, call, report.

Requirements LL-R2 Tests LL-T1 Code LinkedList.c main.c

LL-D3The drawing lives with the list

  • ListPrint draws the chain and appends the node count, and ListCount does the counting.
  • Both walks stop when a circle comes back around to the head, so a circle prints once and says so.

Requirements LL-R3 LL-R7 Tests LL-T2 LL-T6 Code LinkedList.c

LL-D4The menu owns the state and the guard

  • Program state is a head pointer and a flag saying whether the tail points back at it.
  • One guard function refuses the linear operations while that flag is set, in the same words every time.
  • One freeing function serves clear, load and quit: it straightens a circle first, then frees the chain.

The classics

LL-D5Merge sort as three small functions

  • Split in half, merge two sorted lists, and a sort that recurses between them.
  • The merge uses a stack-local dummy head, which removes every "is this the first node" check.

Requirements LL-R4 Tests LL-T3 Code LinkedList.c

LL-D6One two-walker idea, five uses

  • The middle node, the nth from the end, loop detection, the palindrome check and the merge sort split are all two walkers.
  • A head start on the fast walker is what changes the answer: the split and the palindrome check stop one node earlier than the middle does.
  • The palindrome check reuses ListReverse twice and repeats the walk to find where the halves meet, then compares inward.

The circle

LL-D7Rotate by using the circle

  • Bend the list into a circle, walk k steps to the node that becomes the tail, cut there.
  • Walking a circle makes a k larger than the length wrap around at no extra cost.

Requirements LL-R5 Tests LL-T5 Code LinkedList.c

LL-D8The game returns a straight list

  • ListJosephus takes a ring, prints it, unlinks every k-th node, and prints the ring again each round.
  • The survivor comes back as a one-node list, so the caller holds an ordinary list again.

The decisions

LL-D9Decision: numbers are append-only

  • The menu enum is ordered by number, but the menu is displayed by group.
  • So a new item can join its group on screen without renumbering anything.
