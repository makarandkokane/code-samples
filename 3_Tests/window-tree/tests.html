How each requirement was checked, by piping sessions and reading the logs.

Requirements Design Tests Code

Behaviour

WT-T1Every menu item is exercised

  • Drive the program by piping a session, one line per keystroke, through all ten menu items and back out at quit.
  • Pass: every item answers, and so do the mistakes: an unknown widget name, a click on a hidden widget, junk where numbers belong, and an unknown menu choice.

Requirements WT-R2 WT-R4 Design WT-D5 WT-D6

WT-T2The layout logs mirror each other

  • Run the loud layout and read the measure log against the arrange log.
  • Pass: the same nine widgets appear in both, children above their parent in one and below it in the other.
  • The mirror is read on the fixed demo tree, by eye; no harness asserts it.

Requirements WT-R3 Design WT-D1 WT-D7

WT-T3The story of a click, three ways

  • Click Reset while Advanced is disabled, enable Advanced and click again, then click Help.
  • Pass: the first click is swallowed at Advanced, the second bubbles up to Settings and the form resets, and Help's action falls off the top, dropped.

Requirements WT-R5 Design WT-D2 WT-D4

WT-T4The veto, the save, the close

  • Type into the name box so the star appears, ask the window to close, then click Save and ask again.
  • Pass: the first ask shows the box vetoing in its postorder place and the window staying open; after the save the same walk agrees and the demo ends on its own.

Requirements WT-R6 Design WT-D2 WT-D3

WT-T5Hiding reshapes the window

  • Hide the Advanced panel, then look at the screen, the outline, and a click aimed at Reset by name.
  • Pass: the window redraws three rows shorter, the outline tags the panel hidden, and the click is refused because nothing is there to click.

Requirements WT-R4 Design WT-D6

Static check

WT-T6It builds clean and owns cleanly

  • Build Release through CMake with Visual Studio 2022, run clang-format across the sources, and search them for new and delete.
  • Pass: the build succeeds, the format check reports nothing to change, and the search finds neither word: every widget changes hands as a unique_ptr.
