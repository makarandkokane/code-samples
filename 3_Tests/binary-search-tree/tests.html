Binary search tree: tests

How each requirement was checked, with the searches counted and the walks compared.

Requirements Design Tests Code

Behaviour

BT-T1Every menu item is exercised

  • Drive the program by piping a session, one line per keystroke, through all fifteen menu items and back out at quit.
  • Pass: every item answers, the tree redraws after every change, and the count line matches the drawing.

Requirements BT-R2 Design BT-D1 BT-D5

BT-T2The stick, the balance, and the counted search

  • Load the worst case, search for the deepest value, balance, and search again.
  • Pass: the first search reports found in 15 steps at height 15, the balance reports height 15 to 4, the second search reports the same value found in 4 steps, and the inorder is unchanged.

Requirements BT-R4 BT-R5 Design BT-D1 BT-D3

BT-T3The walks check themselves

  • Run all three walk items on the sample tree.
  • Pass: each prints the recursive and the iterative sequence and then its own verdict that the two agree, and the inorder line is sorted.
  • The comparison is in the program, so it runs on every tree a user builds, not just this session's.

Requirements BT-R6 Design BT-D2

BT-T4The threads carry a full walk

  • Build the threaded tree from the sample values, walk it by threads, and list the threads.
  • Pass: the walk equals the main tree's inorder, every node without a right child appears in the thread report, and the rightmost one marks the end of the walk.

Requirements BT-R7 Design BT-D4 BT-D7

BT-T5Wrong input, answered

  • Search, balance and thread an empty tree, walk the threads before building them, insert a duplicate, delete an absent value, and type junk at both prompts.
  • Pass: each case gets its own sentence and the program carries on.

Requirements BT-R3 Design BT-D5

Static check

BT-T6It builds clean and owns what it says

  • Build Release through CMake with Visual Studio 2022, run clang-format across the sources, and search them for new and delete.
  • Pass: the build succeeds, the format check reports nothing to change, and the only new and delete in the demo are ThreadedTree's, exactly as the ownership decision states.
