How the documents link up

  • Every item carries an ID: the project, the kind, the number. OM-R1 is the first requirement of observer-mvc, LL-T5 the fifth test of the linked list.
  • A requirement links forward to the design elements and the tests that carry it, and its page ends with a coverage table.
  • Design and test items link back the same way, and a design item also links the source file it describes.
